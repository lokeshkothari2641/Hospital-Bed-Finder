# Hospital-Bed-Finder
## 🏥 Bed Finder (UI/UX & Frontend Prototype)

A clean, responsive frontend prototype designed to help users quickly locate, filter, and check available hospital beds during emergencies. This project translates a custom Figma wireframe into a static web interface.

🎨 **Figma Wireframe & Prototype:** [View on Figma](https://www.figma.com/proto/xetBxE3OifVYSqCUd9ty1V/Bed-Finder-?node-id=2003-2384&starting-point-node-id=2003%3A2384&t=Pcx1nGqCnQ4kH8Hz-1)

---

## ✨ Prototype Highlights
- **Emergency-First Layout:** High-clarity interface built for rapid scanning and minimal friction.
- **Bed Availability Cards:** Clear visual indicators for general, ICU, and oxygen bed counts across nearby hospitals.
- **Search & Filter UI:** Interactive layout for filtering facilities by location, distance, and bed category.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile viewports.
